## 🔄 Can I Switch Between Versions?

**Yes!** Both versions can be installed simultaneously:

```bash
# Standard Edition
python3 donnie_agent_en.py

# Crypto Edition  
python3 donnie_crypto_agent.py

# Or set up different aliases
alias donnie='python3 ~/.donnie/standard/donnie.py'
alias donnie-crypto='python3 ~/.donnie/crypto/donnie.py'
```
